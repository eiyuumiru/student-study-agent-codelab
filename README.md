## Publishing the Codelab (Organizers)

### Prerequisites

Install the [claat](https://github.com/googlecodelabs/tools) tool:

```bash
go install github.com/googlecodelabs/tools/claat@latest
```

Or download the binary directly from [releases](https://github.com/googlecodelabs/tools/releases/latest) and place it in this directory as `claat.exe`.

### Set up the `starter` branch (one-time)

The `starter` branch contains only the files participants need — no solution code, no docs, no build tools. Cloud Shell clones this branch directly so participants see a clean workspace.

```bash
# From the main branch
git checkout --orphan starter
git rm -rf .

# Copy starter files to root
cp -r starter/* .
cp starter/.env.example .

git add study_agent/ requirements.txt .env.example TUTORIAL.md
git commit -m "init: starter code for participants"
git push origin starter

git checkout main
```

After this, the `starter` branch contains:
```
study_agent/
├── __init__.py
├── agent.py
└── tools.py    ← TODOs for participants
requirements.txt
.env.example
TUTORIAL.md
```

### Export and publish

```bash
bash publish.sh
git add docs/
git commit -m "publish: update codelab"
git push
```

### GitHub Pages setup (one-time)

1. Go to your repo → **Settings** → **Pages**
2. Set **Source** to `Deploy from a branch`
3. Set **Branch** to `main`, folder to `/docs`
4. Save — your site will be live at `https://eiyuumiru.github.io/student-study-agent-codelab/`

## Running the Solution Locally

```bash
cd solution
pip install -r requirements.txt
cp .env.example .env   # Add your GOOGLE_API_KEY
adk web
```

Open http://localhost:8000 and select **study_agent**.
